# 生物遗传题教学软件 · 数据文件说明

本目录为「生物遗传题教学软件」的**数据层**，供 Dart 引擎读取。所有数据均为**联网搜索核实**后整理，每条记录标注来源 URL。**严禁**仅凭训练数据编造数字/真题/考纲条目。

## 文件清单

| 文件 | 内容 | 条目数 | 用途 |
|------|------|--------|------|
| `syllabus_gaokao.json` | 课标遗传与进化条目覆盖表（官方编号骨架，v2.0） | 14 | 考纲覆盖自评 |
| `kaodian_compilation.json` | 遗传考点汇总（含9331全变式） | 36 | 考点知识点查询 |

## 各 JSON 结构

### syllabus_gaokao.json（v2.0）
条目骨架为《课程标准(2017年版2020年修订)》官方编号，经外部整理资料核对。
`covered_by` 显式声明覆盖能力（空数组=明确未覆盖），`partial: true` 表示部分覆盖；
`exam` 段为辽宁新高考考情速览。
```json
{
  "exam": { "title": "...", "duration": "75 分钟", "genetics_weight": "..." },
  "items": [
    {
      "id": "SYL-08",
      "code": "3.2.3",
      "module": "概念3 遗传与进化 · 3.2 有性生殖",
      "kaodian": "考点名称（课标条目转述）",
      "level": "理解/应用",
      "note": "补充说明",
      "covered_by": ["双基因 9331 计算器（含全套变式）"],
      "partial": false,
      "source": "课程标准编号 + 核对来源"
    }
  ]
}
```

### kaodian_compilation.json


## 字段设计约定（供 Dart 引擎读取）
- 统一顶层 `{ "items": [...] }`，字段名自洽，便于反序列化。
- 筛选用字段：`id`、`name`（考点）、`module`（考纲）。
- 所有条目均含 `source` 字段（来源 URL），用于回溯与校验。

## 数据来源汇总
- **9331 变式全表**：北京教育考试院 PDF（`bjeea.cn/uploads/soft/231211/1743期8版PDF.pdf`）+ 21cnjy 二轮讲义（`zy.21cnjy.com/23543079`、`zy.21cnjy.com/25246006`）双重确认。
- **豌豆 7 对性状**：深圳湾实验室（`imp.szbl.ac.cn/original-detail/504.html`）+ 中国农科院（`caas.cn`）。
- **系谱口诀/判断**：头条/学好网/91apu/搜狐。
- **连锁互换**：每日快懂百科 + 21cnjy 微专题。

## 已知缺口 / 待办
1. **官方考纲原文逐条 PDF 未能获取直接 URL**。当前以 21cnjy 复习讲义「课标要求」原文（`zy.21cnjy.com/25246006`）+ 学科网伴性课标要求（`zxxk.com/soft/40648227.html`）代替。若需精确逐条，建议补充官方《普通高中生物学课程标准（2017年版2020年修订）》PDF。
